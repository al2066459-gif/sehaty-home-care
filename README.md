# Sehaty Home Care

Build an app that أنشئ تطبيقاً احترافياً باسم صحتي (Sehaty) للخدمات الطبية المنزلية في ليبيا.

أريد تطبيقاً باللغة العربية مع دعم RTL، وتصميماً مطابقاً قدر الإمكان للتصميم الأصلي الذي اتفقنا عليه سابقاً.

يحتوي التطبيق على:

تسجيل المرضى ومقدمي الخدمات.

حجز زيارة طبيب للمنزل.

طلب التمريض المنزلي.

طلب التحاليل وسحب العينات.

طلب الإسعاف والنقل الطبي.

تحديد الموقع والعنوان.

متابعة الطلبات والحجوزات.

لوحة تحكم للأطباء ومقدمي الخدمات.

لوحة إدارة كاملة.

نظام عمولات للمنصة.

الدفع النقدي، مع تجهيز الدفع الإلكتروني مستقبلاً.

استخدم تصميماً احترافياً مناسباً للهواتف، وألوان وشعار وهوية صحتي الأصلية. ابدأ بالواجهات الرئيسية أولاً ولا تغيّر الهوية البصرية.
